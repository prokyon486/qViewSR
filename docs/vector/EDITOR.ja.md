# ベクターの編集

この機能は `feature/vector-editor` ブランチで開発しています。
qViewSRで生成したSVGの主線・色面を編集します。元の画像ファイルは変更しません。

1. ベクターを生成し、調整パネルの「編集モード」をONにします。
2. 「編集するレイヤー」で主線または色面を選びます。編集開始時は両方のレイヤーを表示します。
3. 変更が終わったら、同じパネルからSVGまたはPNGで保存します。PNGの保存倍率はベクター入力画像が基準です。

## 主線

線をクリックして選択すると、節点とベジエのハンドルが表示されます。
節点をドラッグして位置を変え、丸いハンドルをドラッグして曲がり方を調節します。
「ドラッグで線を追加」をONにして始点から終点までドラッグすると、新しい線を作ります。
追加直後は直線で、追加モードをOFFにしてハンドルを動かすと曲線にできます。
「追加する線の幅」は新しい線の幅です。

「色…」で選択した図形と、次に追加する線の色を指定できます。
選択した線は「削除」またはDeleteで削除します。
一つのSVGパスに複数の線区間が含まれる場合、選択・削除・色変更はそのパス全体に適用します。

## 色面

色面の境界付近を押し、そのままドラッグすると周囲の境界を押し広げたり引き戻したりできます。
「境界変形の範囲」は入力画像のピクセル単位です。境界から離れた内側では、その範囲に境界が入らないと変形しません。
ドラッグ中は選択形状を青い輪郭で示し、マウスを離すと動かした部分を滑らかなベジエで整えます。
他の色面は変更しないため、重なりや隙間ができる場合があります。必要なら隣の面も調整してください。
色面にも「色…」「削除」を使用できます。

## 移動・取り消し・保存

- 編集中の画像移動は **Spaceを押しながら左ドラッグ**。ホイールの拡大・縮小はそのまま使えます。
- 左右キーや前後のファイル移動は、編集モードを終了するまで停止します。
- **Ctrl＋Z**で取り消し、**Ctrl＋Shift＋Z／Ctrl＋Y**でやり直し。ドラッグ1回を1操作として扱います。
- **Esc**または操作中のフォーカス移動で、確定していないドラッグを中止します。
- SVG／PNGにはハンドルや選択枠を含めず、編集した図形だけを保存します。回転・反転も既存の保存処理に従います。

編集モードを終了しても手編集結果を保持し、再び編集・保存できます。同じ編集内容を開き直した場合は取り消し履歴も保持します。
手編集中・手編集結果の保持中は自動生成の設定を無効にします。「手編集を破棄して生成結果へ戻す」を選ぶと編集前に戻り、生成設定を変更できるようになります。
何も編集せず編集モードを終了した場合は、元のレイヤー表示へ戻ります。

編集内容は現在開いている画像の作業状態です。別のファイルを直接開いたりアプリを終了したりする前に保存してください。
保存済みのSVGを読み込んでレイヤー編集を再開する機能は、この編集モードには含まれません。
SVGは最大1GiB、500万パス、3200万区間までです。開始時には入力データ量の64倍＋128MiBを見積もり、現在の空きメモリーの70%以内に収まることを確認します。途中まで読み込んで図形を落とすことはしません。
取り消し履歴は40操作・256MiBを目安に制限します。大きなSVGでは少ない回数になりますが、最低1操作は保持します。
約203MiB・106万パスの画像では、診断用モデルの読み込みが約23秒、取り消しが約26秒、最大メモリーは約11GiBでした。読み込みと大きなSVGの取り消しは別スレッドで処理します。ドラッグ中は選択形状だけを更新し、SVG全体への反映はマウスを離してから行います。
